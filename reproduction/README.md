# Reproduction archive

This directory separates the two empirical evidence lanes used in MEC.

- `reacher/`: frozen one-shot hidden evaluation lineage.
- `idp/`: development-only second-family stress test and falsification history.

The separation is intentional: the Reacher hidden result and the IDP development result have different evidentiary status and should not be combined into a single “cross-family hidden validation” claim.
